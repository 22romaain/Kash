# Kash — Personal Budget Tracker

A clean, minimalist budget tracking web app built as a personal project.

## Features

- **Monthly expense tracking** — log expenses by category with date and description
- **Monthly budget** — set a global budget and track spending in real time
- **Category budgets** — define individual budgets per category with progress bars
- **Annual overview** — visualize budget vs. spending across all months with an interactive chart
- **Expense search** — filter expenses by category or description
- **Edit & delete** — modify or remove any expense after the fact
- **Local storage** — data persists in the browser, no account required

## Tech

Pure HTML, CSS, and JavaScript — no framework, no dependencies.
